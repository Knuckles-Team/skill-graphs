# skill-graphs specifications

These specs follow the ecosystem [spec standard](https://github.com/Knuckles-Team/pipelines/blob/main/reference/spec-standard.md). One spec owns each capability. A contributor must extend an existing spec before a new one.

## Owner

This repository owns the specs with the ID prefix `SG`.

## Local specifications
