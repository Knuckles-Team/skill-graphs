conda install -c conda-forge pandas

## Intro to pandas[#](https://pandas.pydata.org/docs/getting_started/index.html#intro-to-pandas "Link to this heading")
What kind of data does pandas handle?
[Straight to tutorial…](https://pandas.pydata.org/docs/getting_started/intro_tutorials/01_table_oriented.html#min-tut-01-tableoriented)
When working with tabular data, such as data stored in spreadsheets or databases, pandas is the right tool for you. pandas will help you to explore, clean, and process your data. In pandas, a data table is called a [`DataFrame`](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.html#pandas.DataFrame "pandas.DataFrame").
![../_images/01_table_dataframe.svg](https://pandas.pydata.org/docs/_images/01_table_dataframe.svg)
[To introduction tutorial](https://pandas.pydata.org/docs/getting_started/intro_tutorials/01_table_oriented.html#min-tut-01-tableoriented)
[To user guide](https://pandas.pydata.org/docs/user_guide/dsintro.html#dsintro)
How do I read and write tabular data?
[Straight to tutorial…](https://pandas.pydata.org/docs/getting_started/intro_tutorials/02_read_write.html#min-tut-02-read-write)
pandas supports the integration with many file formats or data sources out of the box (csv, excel, sql, json, parquet,…). The ability to import data from each of these data sources is provided by functions with the prefix, `read_*`. Similarly, the `to_*` methods are used to store data.
![../_images/02_io_readwrite.svg](https://pandas.pydata.org/docs/_images/02_io_readwrite.svg)
[To introduction tutorial](https://pandas.pydata.org/docs/getting_started/intro_tutorials/02_read_write.html#min-tut-02-read-write)
[To user guide](https://pandas.pydata.org/docs/user_guide/io.html#io)
How do I select a subset of a table?
[Straight to tutorial…](https://pandas.pydata.org/docs/getting_started/intro_tutorials/03_subset_data.html#min-tut-03-subset)
Selecting or filtering specific rows and/or columns? Filtering the data on a particular condition? Methods for slicing, selecting, and extracting the data you need are available in pandas.
![../_images/03_subset_columns_rows.svg](https://pandas.pydata.org/docs/_images/03_subset_columns_rows.svg)
[To introduction tutorial](https://pandas.pydata.org/docs/getting_started/intro_tutorials/03_subset_data.html#min-tut-03-subset)
[To user guide](https://pandas.pydata.org/docs/user_guide/indexing.html#indexing)
How to create plots in pandas?
[Straight to tutorial…](https://pandas.pydata.org/docs/getting_started/intro_tutorials/04_plotting.html#min-tut-04-plotting)
pandas provides plotting for your data right out of the box with the power of Matplotlib. Simply pick the plot type (scatter, bar, boxplot,…) corresponding to your data.
![../_images/04_plot_overview.svg](https://pandas.pydata.org/docs/_images/04_plot_overview.svg)
[To introduction tutorial](https://pandas.pydata.org/docs/getting_started/intro_tutorials/04_plotting.html#min-tut-04-plotting)
[To user guide](https://pandas.pydata.org/docs/user_guide/visualization.html#visualization)
How to create new columns derived from existing columns?
[Straight to tutorial…](https://pandas.pydata.org/docs/getting_started/intro_tutorials/05_add_columns.html#min-tut-05-columns)
There’s no need to loop over all rows of your data table to do calculations. Column data manipulations work elementwise in pandas. Adding a column to a [`DataFrame`](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.html#pandas.DataFrame "pandas.DataFrame") based on existing data in other columns is straightforward.
![../_images/05_newcolumn_2.svg](https://pandas.pydata.org/docs/_images/05_newcolumn_2.svg)
[To introduction tutorial](https://pandas.pydata.org/docs/getting_started/intro_tutorials/05_add_columns.html#min-tut-05-columns)
[To user guide](https://pandas.pydata.org/docs/user_guide/dsintro.html#basics-dataframe-sel-add-del)
How to calculate summary statistics?
[Straight to tutorial…](https://pandas.pydata.org/docs/getting_started/intro_tutorials/06_calculate_statistics.html#min-tut-06-stats)
Basic statistics (mean, median, min, max, counts…) are easily calculable across data frames. These, or even custom aggregations, can be applied on the entire data set, a sliding window of the data, or grouped by categories. The latter is also known as the split-apply-combine approach.
![../_images/06_groupby.svg](https://pandas.pydata.org/docs/_images/06_groupby.svg)
[To introduction tutorial](https://pandas.pydata.org/docs/getting_started/intro_tutorials/06_calculate_statistics.html#min-tut-06-stats)
[To user guide](https://pandas.pydata.org/docs/user_guide/groupby.html#groupby)
How to reshape the layout of tables?
[Straight to tutorial…](https://pandas.pydata.org/docs/getting_started/intro_tutorials/07_reshape_table_layout.html#min-tut-07-reshape)

Change the structure of your data table in a variety of ways. You can use [`melt()`](https://pandas.pydata.org/docs/reference/api/pandas.melt.html#pandas.melt "pandas.melt") to reshape your data from a wide format to a long and tidy one. Use [`pivot()`](https://pandas.pydata.org/docs/reference/api/pandas.pivot.html#pandas.pivot "pandas.pivot")

to go from long to wide format. With aggregations built-in, a pivot table can be created with a single command. ![../_images/07_melt.svg](https://pandas.pydata.org/docs/_images/07_melt.svg)
[To introduction tutorial](https://pandas.pydata.org/docs/getting_started/intro_tutorials/07_reshape_table_layout.html#min-tut-07-reshape)
[To user guide](https://pandas.pydata.org/docs/user_guide/reshaping.html#reshaping)
How to combine data from multiple tables?
[Straight to tutorial…](https://pandas.pydata.org/docs/getting_started/intro_tutorials/08_combine_dataframes.html#min-tut-08-combine)
Multiple tables can be concatenated column wise or row wise with pandas’ database-like join and merge operations.
![../_images/08_concat_row.svg](https://pandas.pydata.org/docs/_images/08_concat_row.svg)
[To introduction tutorial](https://pandas.pydata.org/docs/getting_started/intro_tutorials/08_combine_dataframes.html#min-tut-08-combine)
[To user guide](https://pandas.pydata.org/docs/user_guide/merging.html#merging)
How to handle time series data?
[Straight to tutorial…](https://pandas.pydata.org/docs/getting_started/intro_tutorials/09_timeseries.html#min-tut-09-timeseries)
pandas has great support for time series and has an extensive set of tools for working with dates, times, and time-indexed data.
[To introduction tutorial](https://pandas.pydata.org/docs/getting_started/intro_tutorials/09_timeseries.html#min-tut-09-timeseries)
[To user guide](https://pandas.pydata.org/docs/user_guide/timeseries.html#timeseries)
How to manipulate textual data?
[Straight to tutorial…](https://pandas.pydata.org/docs/getting_started/intro_tutorials/10_text_data.html#min-tut-10-text)
Data sets often contain more than just numerical data. pandas provides a wide range of functions to clean textual data and extract useful information from it.
[To introduction tutorial](https://pandas.pydata.org/docs/getting_started/intro_tutorials/10_text_data.html#min-tut-10-text)
[To user guide](https://pandas.pydata.org/docs/user_guide/text.html#text)
## Coming from…[#](https://pandas.pydata.org/docs/getting_started/index.html#coming-from "Link to this heading")
Are you familiar with other software for manipulating tabular data? Learn the pandas-equivalent operations compared to software you already know:
![](https://pandas.pydata.org/docs/_images/logo_r.svg)
The `data.frame` data structure as well as packages like `data.frame` for convenient data handling functionalities similar to pandas.
[Learn more](https://pandas.pydata.org/docs/getting_started/comparison/comparison_with_r.html#compare-with-r)
![](https://pandas.pydata.org/docs/_images/logo_sql.svg)
Already familiar with `SELECT`, `GROUP BY`, `JOIN`, etc.? Many SQL manipulations have equivalents in pandas.
[Learn more](https://pandas.pydata.org/docs/getting_started/comparison/comparison_with_sql.html#compare-with-sql)
![](https://pandas.pydata.org/docs/_images/logo_stata.svg)
The `data set` included in the `DataFrame`. Many of the operations known from STATA have an equivalent in pandas.
[Learn more](https://pandas.pydata.org/docs/getting_started/comparison/comparison_with_stata.html#compare-with-stata)
![](https://pandas.pydata.org/docs/_images/logo_excel.svg)
Users of
[Learn more](https://pandas.pydata.org/docs/getting_started/comparison/comparison_with_spreadsheets.html#compare-with-spreadsheets)
![](https://pandas.pydata.org/docs/_images/logo_sas.svg)
`data set` structure, which closely corresponds pandas’ `DataFrame`. Also SAS vectorized operations such as filtering or string processing operations have similar functions in pandas.
[Learn more](https://pandas.pydata.org/docs/getting_started/comparison/comparison_with_sas.html#compare-with-sas)
