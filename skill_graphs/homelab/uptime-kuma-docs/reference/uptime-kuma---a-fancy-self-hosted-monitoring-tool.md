Monitoring Uptime Monitoring uptime for any network service is now a breeze, Uptime Kuma can monitor HTTP and HTTPS URLs, TCP Ports and HTTP(s) Keywords, HTTP and HTTPs JSON queries, Databases, Ping IP addresses or Domain Names, DNS records, Steam Game Servers and even Docker Containers. Beautiful Ping Charts Who doesn’t love looking at a chart for a better view of the data they have. The Ping monitoring data collected by Uptime Kuma is visualized beautifully by being displayed in a chart that is interactive, fluid and easy to understand. These charts are available for every monitored host you have added. Short Monitoring Intervals Uptime Kuma supports very short 20-second monitoring intervals. This means that it can check any hostname, IP, website, Web App, DNS record or Keyword every 20 seconds. This is enterprise-grade monitoring and mostly enough to alert you for any short periods of downtime your infrastructure may be experiencing. SSL Certificate Monitoring TLS/SSL Certificate monitoring is now available for your domains or apps. You can check if the URL is reachable via HTTPS or not and if there are any anomalies or incorrect HTTP status codes being sent along with any SSL expirations coming up so you can renew the TLS certificates in a timely manner. Beautiful UI/UX If a beautiful dashboard and simplicity are what you are after then look no further. Uptime Kuma offers the sleekest of user interface experiences you will ever come across on a monitoring tool. It is modern, fancy, reactive and very responsive to your instructions. Receive Notifications You can receive notifications on the monitored services you have with over 95+ different channels. You can setup Email (SMTP) alerts, Telegram or Signal alerts, Slack Channel alerts, Discord notifications, Splunk, SendGrid, Twilio and even Pushover. Missing a notification for a service, network, app or website is now old school. Host Multiple Status Pages Uptime Kuma allows you to create multiple status pages for specific services or domains. Status pages allow you to set communications between you and your customers in an event of a health issue on your systems, current incidents, outages and any real-time information you can provide as an update. API Keys If you have a Prometheus Metrics Endpoint and would like to access it you can do so in Uptime Kuma with the use of API keys. By default API keys are not used and only basic HTTP authentication method is used for securing access to the Prometheus metrics endpoint. Once an API key is added the basic HTTP authentication method is disabled. Multi-Language support Do you know what would be helpful? It is still being translated to more languages. Right. Uptime Kuma supports two-factor authentication requiring two forms of identification so it can ask for two forms of access IDs to allow you to login. We hope these answer any concerns or queries you may have regarding using this monitoring tool from simple to more complex troubleshooting asks. What is Uptime Kuma? Uptime Kuma is a monitoring tool that allows anyone to monitor any web services such HTTP/HTTPS websites, Apps, TCP Ports, SSL certificates and even MySQL databases. Is Uptime Kuma Free? Uptime Kuma is fully open-source, this means that the codebase and all files are free for anyone to download and use. You do not need to pay any amount to use it. However, if you are going to host it on a server in the Public Cloud, you will have to pay the actual costs of the server. Is Uptime Kuma Safe and Secure to Use? The monitoring tool itself is secure and safe to use, there are thousands of users around the world using Uptime Kuma without a problem. However, it is up to you to secure the hosting environment from security issues where you have it installed and configured. Uptime Kuma Reports service being “Down” but it isn’t. When you get a “Down” alert but are still able to access the service, this usually means that there is a local problem on the network most likely to a misconfiguration in your networking. Check your Firewall or Network Ports for any recent changes. To debug any Docker container specific issues and if there is no connectivity you can SSH into your container and use tools like “curl, ping or iptables” to check if it has outside connectivity and can reach the public internet. How is Uptime Kuma Licensed? Uptime Kuma is licensed under the “ MIT License “. What can Uptime Kuma be used for? Uptime Kuma is primarily used only for monitoring services and infrastructure. It has a broad range of support for different protocols and services such as HTTP/HTTPS, TCP, SSL Certificates, IP Addresses, ICMP Ping and database monitoring. You can use it for something at a hobby-level for monitoring home server projects or even monitor the infrastructure of your business. Is Uptime Kuma the same as Grafana? Uptime Kuma has a more direct focus on providing features to monitor a wide variety of network endpoints. Grafana provides the ability visualise data from sources such as Graphite, Prometheus, VictoriaMetrics into beautiful graphs and dashboards that are highly customizable according to your needs. What is the default Uptime Kuma Login? The default password of Uptime Kuma is just “Password”. However you can reset the admin password via the CLI if you have access to the server. It is highly advisable to always choose a strong password. Uptime Kuma does not have a default login and password. Does Uptime Kuma work with Docker and Docker Compose? You can use both Docker and Docker Compose to deploy Uptime Kuma. It is a method we recommend to deploy as it is the easiest, quickest and most intuitive method of deploying and making changes to this monitoring tool. How many endpoints or websites can I monitor? You can monitor any number of endpoints or monitors as you wish. What you may keep in mind is the hardware specifications of where Uptime Kuma is hosted as monitoring a large number of endpoints will add to CPU and Memory usage depending on your use cases. What is the default port for Uptime Kuma? Configuring Uptime Kuma with default settings will set its default port to listen on “3001”. However, you are free to choose any port number you wish during the installation process. Does Uptime Kuma work with Home Assistant? Home Assistant is an open-source home automation dashboard where you can monitor your smart devices and energy use. You can add Uptime Kuma directly to your Home Assistant setup by installing it as an add-on. Is there an Uptime Kuma Android or iOS App? There are currently no official Uptime Kuma mobile applications developed for Android or iOS. Please refrain from downloading unofficial apps as you risk your data being leaked or misused. However, you can still access the Uptime Kuma dashboard on your mobile phone as it is mobile-friendly. Can Uptime Kuma monitor LLMs? Uptime Kuma can monitor something like llama.cpp but only as a generic service endpoint. If llama.cpp is running, let’s say in a server mode exposing an HTTP API then it can monitor /health or /completion. However, it does not understand LLMs specifically and is not an LLM monitoring tool. Are Uptime Kuma and UptimeRobot the same ? Uptime Kuma and UptimeRobot are both different monitoring tools. They are not the same. The major difference separating the both is that Uptime Kuma is open-source and free for all its features including unlimited monitors. Whereas UptimeRobot limits its “free” tier to only 50 monitors and a basic status page. Is there an Uptime Kuma Helm Chart available?
