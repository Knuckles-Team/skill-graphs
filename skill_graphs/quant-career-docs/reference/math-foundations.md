# Math You Actually Need (Months 1–4)

You don't need to memorize every proof. You need comfort with these topics to the
point where they stop feeling scary.

## Linear Algebra
Matrices, eigenvalues, vector spaces. Used constantly in portfolio optimization
and factor models.
- Khan Academy
- *Linear Algebra Done Right* — Axler

## Calculus
Derivatives, integrals, differential equations. Options pricing (Black-Scholes)
requires this.
- 3Blue1Brown, *Essence of Calculus* (YouTube) — the best starting point ever made

## Probability & Statistics — the core engine
Distributions, Bayes' theorem, hypothesis testing, stochastic processes. **If you
understand only one mathematical area deeply, make it this one.**

## Optimization
How do you find the best allocation? Linear programming, gradient descent. This is
how modern portfolio theory actually works.

## Free, sufficient resources
- **MIT OpenCourseWare** — has all of this, free.
- **Coursera: "Mathematics for Machine Learning"** specialization — covers most of
  it in ~3 months.

You do **not** need a university course to start.
