Step 1: SSH onto your server where Uptime Kuma is installed: ssh your-user@your-server-ip Now run the following command with a root user or a user with sudo permissions, and replace &lt;enter container name here&gt; with your own container name which you can get by running the “docker ps” command: docker exec -it &lt;enter container name here&gt; bash Once you exec into the container, run the following command it will ask you to provide a new password: npm run reset-password If you have Uptime Kuma Installed directly on your Linux or Windows server, please change to the directory where Uptime Kuma is located on your server and run the following command: npm run reset-password Reset or Remove your 2FA/MFA from Uptime Kuma 2FA and MFA enhance the security of your login.
